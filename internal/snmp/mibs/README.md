# Built-in MIB modules

These are the standard MIB modules published by the IETF and IANA (in the RFCs named in each module's
MODULE-IDENTITY), unchanged, as distributed with Net-SNMP and other SNMP tools. Each module keeps its own
copyright notice. Vendor MIBs (Extreme, VOSS and others) are not included: load them in the SNMP Browser
(Load MIB…).
